Glass Ballot

Encrypted voting with a public audit trail

1 Key ceremony

Generates the trustee's Paillier key and the authority's RSA key, then issues a signed credential to each voter. Starting a new election discards the current one.

2 Voting booth

Your choice is encrypted as one ciphertext per candidate, with zero-knowledge proofs that each holds 0 or 1 and that they add up to 1. In this demo the server encrypts on the voter's behalf; in-browser encryption is the next phase.

3 Close, tally and audit

Closing multiplies all ballots together (the product decrypts to the sum), and the trustee decrypts each candidate's total once, with a proof that the decryption is correct.

Re-checks everything using only the bulletin board. No keys, no trust in the server.
