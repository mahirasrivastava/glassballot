Glass Ballot Encrypted voting with a public audit trail
    How it works

    Helios-style verifiable voting

    Every vote secret.
    Every count provable.

    Your browser encrypts the ballot with Paillier and proves it is valid. The server adds ballots up while still encrypted, and only all the trustees together can open the totals. Anyone can check every step on the public bulletin board.

    • 🔒
      Encrypted on your deviceThe server never sees a vote or a voter's private key.
    • ∑
      Homomorphic tallyMultiplying ciphertexts adds the votes. No single ballot is ever decrypted.
    • ⚿
      Split decryption keyEvery trustee holds one share. Nobody can decrypt alone, not even the server.
    • ✓
      Publicly verifiableSignatures, zero-knowledge proofs and a hash chain anyone can re-check.

        Registration codes

        In a real election each code goes to one eligible voter (by post or e-mail). A code can register exactly one device key, and the server keeps only its SHA-256 hash for checking. For the demo, Use on this device hands the code to the booth.

          Close the polls

          Stops voting and posts a close entry that commits to the exact set of ballots. After this, the trustees can decrypt the totals.

          Trustee key shares

          The decryption key was split into k shares, and the server deleted them after handing them over. Give each file to a different trustee. For the demo, they are also kept in this browser's Trustees tab.

                  Trustees

                  After the polls close, each trustee's own device recomputes the encrypted totals from the public board and raises them to its secret share: Pⱼ = (T mod n)^sⱼ mod n. The product of all the partials is the randomness R of the total, which opens it: gᵐ·Rⁿ = T. Any trustee who is missing, or who submits a wrong partial, means nothing opens.
